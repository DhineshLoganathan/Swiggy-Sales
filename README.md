# Swiggy-Sales
📊 Excel Sales Analysis Dashboard

This repository contains an Excel-based Analysis Dashboard built using Pivot Tables, charts, and data transformation formulas. The dashboard provides meaningful insights using automated analysis and clean visualizations.

🚀 Project Overview

This project demonstrates how raw Excel data can be transformed into an interactive dashboard for business analysis.

Key components included:

✅ Dashboard

Interactive charts for KPIs

Time-based trends (Day, Week Number, Quarter)

Slicers for dynamic filtering

✅ Pivot Tables

Aggregated views for sales/transactions

Automatic date grouping (Months, Quarters, Years)

Drill-down capability for detailed insights

✅ Data Transformations

Extracted Day, Week Number, Quarter from order_date

Used Excel formulas for cleaning and shaping data
